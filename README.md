# Catálogo de servicios informáticos

Sitio estático basado en **Dimension**, plantilla de HTML5 UP.

## Estructura

- `index.html`: contenido del catálogo.
- `assets/css/`: estilos originales y ajustes del catálogo.
- `assets/js/`, `assets/webfonts/`, `images/`: recursos de Dimension.

La plantilla Dimension de HTML5 UP se distribuye bajo licencia Creative Commons Attribution 3.0 (CC BY 3.0). Consulta `LICENSE.txt`.
